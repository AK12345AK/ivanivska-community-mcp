# 🇺🇦 MCP Території України

**Ukraine Territorial MCP — відкрита інфраструктура територіальних даних України для людей, розробників і ШІ-агентів.**

Проєкт розвиває **Благодійний фонд «Україна цифрова»**.

🌐 https://ukrdigital.org

## Про проєкт

Мета — зробити офіційні відкриті дані про території України доступними через єдиний стандартизований інтерфейс **Model Context Protocol (MCP)**.

Проєкт починався з Іванівської територіальної громади Чернігівської області, а згодом був масштабований на всю Україну.

## Територіальне покриття

Джерело — КАТОТТГ, редакція від 7 липня 2026 року.

| Тип територіального запису | Кількість |
|---|---:|
| Області | 24 |
| Автономна Республіка Крим | 1 |
| Райони | 136 |
| Територіальні громади | 1 772 |
| Міста | 461 |
| Селища | 1 979 |
| Села | 27 261 |
| Райони в містах | 108 |
| Міста зі спеціальним статусом | 2 |
| **Усього** | **31 744** |

Каталог містить дев'ять типів записів. Показник 31 744 охоплює не лише населені пункти, а й адміністративні та територіальні одиниці.

## Публічні MCP

**Національний MCP:**

`https://community.ukrdigital.org/mcp/ukraine/mcp`

**Територіальний MCP — приклад села Количівка:**

`https://community.ukrdigital.org/mcp/UA74100110090080359/mcp`

Шаблон територіального маршруту:

`https://community.ukrdigital.org/mcp/{KATOTTG_CODE}/mcp`

MCP використовує Streamable HTTP через HTTPS.

## Інструменти національного MCP

| Інструмент | Призначення |
|---|---|
| `get_catalog_info` | Відомості про каталог |
| `search_territories` | Пошук територій |
| `search_territories_detailed` | Деталізований пошук |
| `get_territory` | Дані конкретної території |
| `get_hierarchy` | Адміністративна ієрархія |
| `list_territories` | Перелік територій за фільтрами |
| `get_mcp_endpoint` | Адреса територіального MCP |
| `list_oblasts` | Перелік областей |
| `list_first_level_territories` | Території першого рівня |
| `list_special_territories` | Спеціальні території |
| `get_welcome` | Інформація про проєкт та його розвиток |

**Разом: 11 інструментів.**

Кожен територіальний MCP надає сім інструментів, зокрема для отримання профілю території, джерел та привітання.

## Що вже реалізовано

- Офіційний каталог 31 744 територіальних записів.
- Класифікація дев'яти типів територій.
- Пошук за назвами та кодами КАТОТТГ.
- Адміністративна ієрархія територій.
- Національний MCP і окремі територіальні маршрути.
- Зіставлення 24 обласних рад із кодами ЄДРПОУ.
- Інформаційний інструмент `get_welcome`.
- Публічний HTTPS-доступ.

## Що в роботі

- Зіставлення територіальних громад із відповідними радами та кодами ЄДРПОУ.
- Контроль якості й актуальності відкритих даних.
- Підготовка системи зворотного зв'язку.

## Що заплановано

- Рішення органів місцевого самоврядування.
- Публічні закупівлі та бюджети.
- Декларації та інші перевірені відкриті дані.
- Поступове розширення інформаційних профілів територій.

## Технології

Python, MCP SDK, Starlette, Uvicorn, Nginx, HTTPS, JSON.

## Важливе застереження

Не всі заплановані джерела вже підключені. Дані потрібно використовувати з урахуванням їхнього офіційного джерела та дати актуальності.

Зіставлення території з радою або іншою юридичною особою потребує окремої перевірки.

Інструмент `submit_feedback` наразі не доступний публічно.
