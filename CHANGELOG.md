# Історія розвитку MCP Території України

## 18 жовтня 2026 — Національна територіальна інфраструктура

### Реалізовано
- Каталог 31 744 територіальних записів КАТОТТГ.
- Класифікацію дев'яти типів територій.
- Пошук та адміністративну ієрархію.
- Національний MCP із 11 інструментами.
- Територіальні MCP із сімома інструментами.
- Новий інструмент `get_welcome`.
- Публічну перевірку `get_welcome` через HTTPS для національного MCP та села Количівка.
- Резервну копію стабільної версії на сервері.

### Дані
- Використовується КАТОТТГ від 07.07.2026.
- Підготовлено зіставлення 24 обласних рад із ЄДРПОУ.
- Триває робота над зіставленням 1 772 територіальних громад із радами.

### Відкладено
- Публікацію `submit_feedback` до завершення захисту від зловживань.
- Поштові сповіщення про звернення.

## Початковий етап — Іванівська громада

- Створено MCP Іванівської територіальної громади.
- Підготовлено 17 MCP для її населених пунктів.
- Реалізовано базові профілі територій та доступ до джерел.
- Використано КАТОТТГ і географічні дані OpenStreetMap/Nominatim.
- Налагоджено HTTPS-доступ до MCP.

Подальший розвиток проєкту передбачає поєднання територіальних профілів із рішеннями рад, бюджетами, закупівлями та іншими відкритими даними.
